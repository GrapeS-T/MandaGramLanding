# MandaGramLanding

Официальный сайт [MandaGram](https://mandagram.com) — Telegram-клиента для компьютера. Здесь можно познакомиться с проектом и командой, узнать о приложении и найти справочные материалы.

Этот репозиторий содержит сайт, а само приложение разрабатывается в [репозитории MandaGram](https://github.com/GrapeS-T/MandaGram).
